# My Guide to Nakameguro (中目黒案内)

> *"Where Tokyo's quiet starts."*

A minimalist, zen-inspired web guide exploring Nakameguro — the serene threshold where the bustling neon rhythm of central Tokyo meets gentle residential tranquility.

## 🌸 Featured Spots

1. **[Starbucks Reserve Roastery Tokyo](./starbucks.html)** — Four-story architectural temple along the Meguro River designed by Kengo Kuma.
2. **[Donki (Don Quijote Nakameguro)](./donki.html)** — The quirky flagship megastore right at the gateway to the neighborhood.
3. **[Onibus Coffee](./onibus.html)** — Artisanal micro-roastery in a vintage wooden house beside the passing trains.
4. **[The Shotengai (Nakameguro Ginza)](./shotengai.html)** — Pedestrian shopping street and Koukashita arcade full of bakeries, cafes, and local charm.
5. **[Beef Kitchen](./beef-kitchen.html)** — Modern, clean wagyu yakiniku dining.

## 🌐 Deploying to GitHub Pages

1. In your GitHub repository: [kagelump/myfirstwebsite1](https://github.com/kagelump/myfirstwebsite1)
2. Go to **Settings** > **Pages**.
3. Under **Build and deployment** > **Source**, choose **Deploy from a branch**.
4. Select `main` (or your default branch) and `/ (root)`.
5. Click **Save**.
6. Your site will be live at:
   `https://kagelump.github.io/myfirstwebsite1/`
